# Notebooklab Cursor Starter Bundle

This is a tracked public-ready starter bundle for Cursor-style MCP usage.

It exists to make Notebooklab easier to wire into Cursor without pretending there is already a public plugin, marketplace package, or official Anysphere partnership surface.

## What it contains

- `.mcp.json`
- `.cursor/commands/notebooklab-mcp-outcome-workflows.md`
- `skills/notebooklab-mcp-outcome-workflows/SKILL.md`

## What it is for

- public-ready Cursor starter package distribution through this repository
- read-first Notebooklab MCP workflows
- notebook draft / research-thread / auditable-run starter actions

## How to use it

1. Confirm `notebooklab-mcp` is available in the environment that launches Cursor.
2. Register the bundle-local MCP config using the current Cursor MCP flow.
3. Copy or point Cursor at the checked-in command markdown if you want a repo-owned read-first workflow prompt.
4. Start with one read-first step:
   - list drafts
   - list research threads
   - list auditable runs
5. Only after that move to a narrow write-oriented action.

## Boundary

- public-ready package available from this repository
- not a public Cursor plugin claim
- not a marketplace or directory listing
- not an official partnership or endorsement claim
