# Code of Conduct

## Our Standard

We want Notebooklab to be a respectful, constructive, and low-drama collaboration space.

Examples of behavior that helps the project:

- Being respectful in technical disagreement
- Giving actionable, evidence-based feedback
- Assuming good intent while still being honest about risks
- Focusing criticism on ideas, code, and process rather than people

Examples of unacceptable behavior:

- Harassment, insults, or personal attacks
- Discriminatory or exclusionary language
- Publishing private information without permission
- Repeatedly derailing review or support threads
- Threats, intimidation, or bad-faith escalation

## Scope

This Code of Conduct applies to:

- GitHub issues, pull requests, and discussions
- Community support spaces linked from this repository
- Project-maintained review, planning, and support interactions

## Reporting

If you experience or witness unacceptable behavior:

- For general conduct concerns, contact maintainers through the support routes documented in [SUPPORT.md](SUPPORT.md)
- For security-sensitive or privacy-sensitive incidents, follow [SECURITY.md](SECURITY.md)

## Enforcement

Project maintainers may remove, edit, or reject content that violates this Code of Conduct. Repeated or severe violations may result in temporary or permanent removal from project spaces.

Enforcement decisions are made by maintainers based on repository safety, collaboration quality, and user impact.
