# Support

This support guide is for the current fork in this repository.

> In plain language: if you need help, start with the docs and the repo you are standing in now. Do not assume the upstream project is the help desk for this checkout.

## Start Here

Use repository-local documentation first:

- docs portal: [docs/index.md](docs/index.md)
- installation: [docs/installation.md](docs/installation.md)
- configuration: [docs/configuration.md](docs/configuration.md)
- development: [docs/development.md](docs/development.md)

## Which Path To Use

### Usage or setup help

Open a GitHub Discussion in this repository after checking the docs above.

Use Issues when you already have a reproducible bug, docs defect, or scoped implementation problem.

### Reproducible bugs or documentation fixes

Use this repository's GitHub `Issues` tab and include:

- commit SHA or release version
- environment details
- reproduction steps
- relevant logs or screenshots

### Security-sensitive reports

Do not use public issues. Follow [SECURITY.md](SECURITY.md).

### Contribution questions

Read [CONTRIBUTING.md](CONTRIBUTING.md) and [MAINTAINERS.md](MAINTAINERS.md) before opening work that depends on stewardship decisions.

## What This Fork Does Not Promise

- no 24/7 support coverage
- no public Discord or off-repo help desk declared in-tree
- no guarantee that upstream maintainers will triage this fork's issues
- no guarantee that every environment-specific problem can be reproduced

## Stewardship Boundary

Fork provenance lives in [NOTICE.md](NOTICE.md). Current intake and responsibility boundaries live in [MAINTAINERS.md](MAINTAINERS.md).
