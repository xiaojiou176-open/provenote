# Notebooklab Public Skills

This directory keeps the standalone public skill packets that are ready to be
submitted to host-specific skill registries without pretending those listings
are already live.

## Current packets

- `notebooklab-mcp-outcome-workflows/`
  - canonical host-facing skill folder for OpenHands/extensions and
    ClawHub-style submit flows

## Truth boundary

- These folders are repo-owned submission materials.
- They are not proof of a live OpenHands/extensions or ClawHub listing.
- They do not replace the first-party MCP server, the `notebooklab` CLI, or the
  core long-context product path.
