## Short Pitch Set

### Product one-liner

`Long-context-first workbench for structured insight, auditable markdown, and notebook outcomes.`

### Distribution one-liner

`Public-ready starter bundles for Claude Code, Codex, and OpenClaw-compatible installs, backed by a first-party MCP server and operator workflows.`

### Safe external wording

`Public-ready install packages are available today. Official marketplace or registry listings are only claimed once they are actually live.`

## Suggested Demo Flow

1. Show the README first screen and hero image.
2. Show the shortest path from source import to auditable markdown.
3. Show one host starter bundle page.
4. Show the distribution ladder so the audience can see what is live and what is still external.
5. End on the MCP or operator surface, not on unverified marketplace claims.

## Current Boundary

- This kit is repo-owned and evidence-backed.
- It supports social preview upload, marketplace submission prep, and promo-script preparation.
- It does **not** by itself prove that any official listing is already live.
- It does **not** replace owner-only login, settings, or submit steps.
